** Publish org file as multiple HTML pages

using =html-multi-page-artifact=

I sometimes want to structure a big org file into chew-able pieces. For example documentation of a
project. In such cases, I often have a single org file which is rather long, but when published, I
want to produce a nice documentation site with certain sections on their own separate HTML pages.

This artifact accepts a tree of content, and produces multiple HTML pages that fit together well.
