Based on Noun Groups

All the nouns falling in a particular group, i.e nouns following a general theme associates with a particular gender regardless of how they end.

  1. Masculine groups
    • Months and seasons
    • Weather elements
    • Currency
  2. Feminine groups
    • Trees
    • Fruits
    • Flowers
    • Numbers
  3. Neuter noun groups
    • Metals
    • Countries
    • Hotels
