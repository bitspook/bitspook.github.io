difference - Usage of "etwas" and "einige"

January 20, 2024
  • There is no definitive rule. There is a pattern, but it has exceptions
  • Einige: some/several
    • for specific, countable quantities
    • Example:

      • Ich brauche einige Stücke frisches Fleisch.

        I need a few pieces of fresh meat.

  • Etwas: some/a little
    • for abstract quantities
    • Example:

      • Ich brauche etwas frisches Fleisch.

        I need some fresh meat.
